# UI Selection Screen

## Programma

ZFM_VISU_MANDATI

## Scopo

La schermata permette la ricerca e consultazione di liquidazioni e mandati tramite un insieme esteso di criteri di filtro.

## Filtri principali

### Mandati

- Mandato (da/a)
- Data numerazione mandato (da/a)
- Anno mandato (da/a)

### Liquidazioni

- Anno liquidazione (da/a)
- Numero liquidazione (da/a)
- Numero reintegro (da/a)

### Struttura organizzativa

- GSA
- Centro di responsabilità
- Capitolo
- Fondi
- Impegno

### Contabilità

- Conto finanziario
- Data scadenza impegno
- Stato

### Beneficiari

- Beneficiario
- Beneficiario alternativo

### Monitoraggio

- Data modifica
- Giorni alla scadenza DURC

### Tracciabilità

- Codice CIG
- Codice CUP

### Dati Atto

#### Proposta

- Anno proposta
- Numero proposta
- Direzione proposta
- Tipo provvedimento

#### Provvedimento

- Anno provvedimento
- Numero provvedimento
- Direzione provvedimento
- Tipo provvedimento
- Data provvedimento

## Opzioni

### Output

- Layout
- Cespiti
- Informazioni aggiuntive

## Considerazioni ICC

Questa schermata dovrà essere mappata in:

- Fiori Elements Filter Bar
- RAP Query Parameters
- CDS Consumption Filters
- Value Help CDS
